# pillayarnonbu2026.com

Pillayar Nonbu 2026 official hosting repository.

## Static Site

This repository is set up as a simple static GitHub Pages site generated from Hugo. The generated HTML and assets are committed at the repository root, including `index.html`, so GitHub Pages can serve the site without a workflow.

Pages:

| Page | Purpose |
| --- | --- |
| File | Purpose |
| --- | --- |
| `index.html` | Static home page generated by Hugo |
| `pillayar-nonbu-2026.html` | Static Pillayar Nonbu event page generated by Hugo |
| `assets/` | Static CSS, theme images, and event images |
| `content/` | Hugo source content for future edits |
| `layouts/` | Hugo templates |

## Local Development

Run:

```bash
hugo server
```

Build:

```bash
hugo --gc --minify
```

After building, copy the generated files from `public/` to the repository root before committing:

```bash
cp public/index.html .
cp public/pillayar-nonbu-2026.html .
cp public/robots.txt .
cp public/sitemap.xml .
cp -R public/assets .
```
